# Python Interview Practice

## Overview

This folder contains my Python interview preparation and problem-solving practice.

The goal is to strengthen my Python fundamentals and gradually prepare for technical interviews at companies such as Google, Amazon, and Meta.

The questions and problems are based on the concepts I am learning through my Python projects.

## Learning Approach

I am following a hands-on approach:

1. Understand the problem.
2. Try to write the solution myself.
3. Run the code.
4. Debug errors.
5. Improve the solution.
6. Add the solution to GitHub.
7. Gradually increase the difficulty.

The focus is on understanding the logic rather than memorizing solutions.
